# Static assets

## logo.png  (required)

Save the Hetex horse mark here as `logo.png`. It is used in the sidebar, on
the empty-chat screen, and on the login and register pages.

- Square, transparent background
- 512x512 or larger — it renders at up to 72px and needs to stay sharp on
  high-DPI screens

Until the file exists the interface falls back to a gradient "H" monogram, so
nothing appears broken — but the real mark is what should be there.
